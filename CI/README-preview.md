# Просмотр готовых материалов

## Единый курс

Для просмотра теории, банка и семинаров 1–7 соберите профиль преподавателя:

```sh
bash CI/render.sh full
```

Откройте `_site-full/index.html`: в карте курса доступны теория, банк
и слайды. Тема 6 — «Доверие к данным», тема 7 — «Сохранность данных».
Решения находятся в банке full; в презентациях остаются только условия.
Обычные страницы можно читать локально без сервера. Интерактивы OJS
требуют HTTP-доступа; основной рассказ и условия слайдов доступны без них.
Меню курса работает и при открытии файлов: переходы ведут на `index.html`
соответствующего раздела. Устройство локальной поправки Navigation описано
в [реестре пакетов](../UPSTREAM.md).

После правок выполните полную сборку нужного профиля и обновите страницу.
Сборки запускайте последовательно; во время рендера не меняйте исходники,
документацию и конфигурацию. Course Core проверяет снимок проекта.

## Общий сайт через Python

Из корня курса:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory _site-student
```

Откройте <http://127.0.0.1:8000/>. Остановка — `Ctrl+C`.
Для преподавательского сайта замените каталог на `_site-full`.
Сервер показывает существующие файлы и не запускает Quarto. После пересборки
обновите страницу браузера. Отдельные экспорты подпроектов не обновляют общую
копию сайта автоматически.

## Отдельные экспорты через nginx

`CI/preview-nginx.sh` обслуживает готовый портал и подпроекты из их каталогов.
Нужны `nginx`, Python 3 и обычные утилиты Linux. Запускайте от своего
пользователя, без `sudo`:

```sh
./CI/preview-nginx.sh start
./CI/preview-nginx.sh status
./CI/preview-nginx.sh stop
```

По умолчанию используются профиль `student` и свободный порт на `127.0.0.1`.
Для постоянного адреса укажите порт; для преподавательского просмотра — `full`:

```sh
./CI/preview-nginx.sh start student 58387
./CI/preview-nginx.sh start full 58388
```

| Маршрут | Каталог для `student` |
| --- | --- |
| `/` | `_site-student/` |
| `/theory/` | `theory/_output/student/` |
| `/task/` | `task/_output/student/` |
| `/seminars/` | `seminars/_output/student/` |

Для `full` используются `_site-full/` и `_output/full/`. В каждом каталоге
должен существовать `index.html`, иначе скрипт остановит запуск с сообщением
о недостающем экспорте. Для отсутствующих страниц и ресурсов работающий сервер
возвращает `404`.
После точечной пересборки подпроекта достаточно обновить страницу;
принудительное кеширование отключено.

Повторный `start` показывает уже работающий экземпляр. Для смены порта сначала
выполните `stop`. Конфигурация, PID и журналы находятся в отдельном временном
каталоге, путь к которому печатает скрипт. Системная конфигурация nginx
не меняется; адрес доступен только на этой машине.

Для OJS нужны HTML, модули, данные и SVG из готового экспорта. Открывайте
страницы по HTTP: обращение через `file://` не обеспечивает загрузку модулей.
