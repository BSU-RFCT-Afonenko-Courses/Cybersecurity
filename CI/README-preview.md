# Локальный просмотр готового сайта

Основной способ — одна команда из корня курса:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory _site-student
```

Откройте <http://127.0.0.1:8000/>. Сервер автоматически отдаёт `index.html`;
браузер нужно открыть вручную. Остановка — `Ctrl+C`.
Для другого готового сайта замените `_site-student` на его каталог, например
`_output`. Вместе с HTML в нём должны находиться необходимые модули, данные
и изображения OJS. После пересборки обновите страницу браузера.

Сервер показывает существующие файлы и не запускает сборку. Изменения должны
попасть в выбранный выходной каталог; отдельные экспорты подпроектов сами по
себе не обновляют общую копию сайта. Для просмотра достаточно Python 3.7
или новее, без дополнительных библиотек и зависимости от расширений курса.

## Ранее подготовленный просмотр через nginx

Скрипт `CI/preview-nginx.sh` показывает готовые экспорты курса по HTTP. Он не
запускает сборку Quarto. Для работы нужны установленные `nginx`, `python3`
и обычные утилиты Linux. Запускайте от своего пользователя, без `sudo`.

Из корня репозитория:

```bash
./CI/preview-nginx.sh start
./CI/preview-nginx.sh status
./CI/preview-nginx.sh stop
```

По умолчанию используется профиль `student` и свободный порт на `127.0.0.1`.
Команда `start` печатает адрес портала и главы об управлении доступом. Для
постоянного адреса можно указать свободный порт:

```bash
./CI/preview-nginx.sh start student 58387
```

Повторный `start` показывает адрес уже работающего экземпляра. Чтобы сменить
порт, сначала выполните `stop`. Профиль `full` выбирается вторым аргументом
каждой команды; для него должны существовать все соответствующие экспорты.

| Маршрут | Каталог готового экспорта для `student` |
| --- | --- |
| `/` | `_site-student/` |
| `/portal/` | Перенаправление на `/` |
| `/theory/` | `theory/_output/student/` |
| `/task/` | `task/_output/student/` |
| `/seminars/` | `seminars/_output/student/` |

Для `full` используются `_site-full/` и `_output/full/`. При отсутствии
`index.html` хотя бы одного раздела запуск завершится с понятным сообщением.
Главы и ресурсы разделов читаются напрямую из их экспортов: после точечной
пересборки страницы достаточно обновить браузер. Переносить весь сайт заново
не требуется. Принудительное кеширование отключено.

Открывайте выданный HTTP-адрес. OJS загружает модули из
`/theory/_prepared/visualizations/…`, включая относительные импорты и SVG.
Конфигурация задаёт для JavaScript тип `application/javascript`, для SVG —
`image/svg+xml`. Вместо отсутствующих файлов сервер возвращает `404`.

Конфигурация, PID, временные файлы и журналы этого экземпляра находятся в
отдельном каталоге `${TMPDIR:-/tmp}/cybersecurity-nginx-…`; точный путь печатает
скрипт. Системная служба nginx и её конфигурация не изменяются. Адрес доступен
только на этой машине. После перезагрузки запустите `start` снова.
