# Тема БГУ для учебных материалов

`bsu-theme` оформляет книги HTML и презентации Reveal.js в обычных форматах Quarto.
Палитра взята из предоставленного брендбука БГУ (RGB, страница 10), Arial
используется как предусмотренный им резервный шрифт. Пакет не распространяет
закрытые шрифты и не воспроизводит заново официальный логотип или орнамент.

Тема подключается явно в проекте. Установка общего набора расширений сама по себе
не меняет оформление курса. `_extension.yml` содержит описание ресурсов,
необходимое для установки пакета:

```yaml
brand: _extensions/bsu-theme/_brand.yml
format:
  html:
    theme:
      - cosmo
      - brand
      - _extensions/bsu-theme/styles/common.scss
      - _extensions/bsu-theme/styles/book.scss
  revealjs:
    theme:
      - default
      - brand
      - _extensions/bsu-theme/styles/common.scss
      - _extensions/bsu-theme/styles/slides.scss
```

Оставьте только форматы, используемые проектом. Пути отсчитываются от его корня.
Если `quarto add` разместил пакет в каталоге владельца, укажите фактический путь.
Эту настройку можно вынести в `_bsu.yml` и подключить через
`metadata-files: [_bsu.yml]`. Quarto объединяет массивы, поэтому базовую тему и
каждый SCSS-файл нужно перечислять один раз.

Управление слайдами подключается отдельно:
`format.revealjs.revealjs-plugins: [course-navigation]`. Тема задаёт ему цвета
через `common.scss`. Для стандартного оформления достаточно убрать `brand` и
SCSS из настроек; учебная разметка и её поведение от темы не зависят.

Внешний вид учебных блоков задаётся переменными `--course-accent`, `--course-muted`,
`--course-border`, `--course-surface`. Размещение `.course-block`,
`.course-metadata` и `.course-answer` обеспечивает `course-presentation`.
Автор использует общую разметку упражнений, решений и учебных ролей.

SCSS применяется к HTML, Reveal и PDF, напечатанному браузером. Для LaTeX и Beamer
брендированный шаблон в этот пакет не входит; учебное содержимое при этом
сохраняет фильтр представления.
