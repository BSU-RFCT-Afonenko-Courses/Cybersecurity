# Организация исходников курса

`theory/` содержит теорию по темам, `task/bank/` — единые условия задач и решения,
`task/works/` — состав занятий и работ, `seminars/` — только слайды и их каталог.
Идентификаторы задач и работ сохраняются при переносе между страницами.
`control-works/` содержит печатные бланки; общие стили отделены от вариантов.

Общие авторские материалы доступа находятся в `shared/access-control/`.
Имена и подписи меняются в `example.yml`, поведение — в `example.mjs`,
композиции — в `diagram.mjs`. `node CI/build-access-examples.mjs` обновляет SVG и
браузерный скрипт, без Quarto. Генератор больше не создаёт qmd с HTML, CSS или JS.

В теории и слайдах картинки включаются обычным Markdown. Виджет задаётся native Div:

```markdown
::: {.acx-widget data-access-model="mac"}
Измените параметры, чтобы проследить решение.
:::
```

Локальный `filters/access-examples.lua` подключает браузерные зависимости только на
страницах с виджетами и переносит SVG через Pandoc media bag. Это позволяет общей
папке исходников работать в самостоятельных подпроектах и собранном курсе.
Общий механизм библиотечных виджетов исследуется в отдельной экспериментальной ветке.

Отложенные учебные дополнения: `docs/drafts/access-control/`.
История разработки и источники: `docs/seminar-4/`. Старые схемы, нужные черновику
о сеансах, сохранены в `docs/drafts/access-control/legacy/` и не публикуются.

Основной и полный профили имеют одинаковые тематические входы; преподавательская
страница остаётся только в полном профиле, архив черновиков не публикуется. Алиасы поддерживают прежние адреса задач.
