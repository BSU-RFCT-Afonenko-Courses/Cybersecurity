# Ручная правка схем контроля доступа

Авторский источник — `shared/access-control/example.yml`.
Он содержит имена участников, названия ресурсов, роли, три уровня MAC,
подписи картинок, элементы управления и объяснения решений. В нём нет
координат, SVG-тегов, CSS или обработчиков браузера.

Меняйте значения `label`, `processLabel`, `file` и тексты в `labels`, `messages`, `widget`.
Служебные идентификаторы `lena`, `boris`, `handout`, `draft`, `answers`,
`read`, `write`, `edit`, `copy` сохраняйте: по ним связаны сущности.
Одинарные/двойные кавычки YAML нужны, если текст содержит двоеточие;
для длинной фразы можно использовать `>-`, а для ручного переноса строки на рисунке — `|`. Отступы делайте пробелами. Например:

```yaml
objects:
  answers:
    label: |
      Ответы
      к экзамену
    file: answers.txt
    level: 3
```

После правки из корня рабочего дерева выполните:

```bash
node CI/build-access-examples.mjs
```

Эта команда обновляет только схемы и виджеты, без пересборки Quarto.
Для неё нужны Node.js и Python 3 с PyYAML. Данные читаются через `yaml.safe_load`.
Браузеру не нужны Python, PyYAML, доступ к сети или внешние библиотеки.
Проверка актуальности сохранённых результатов:

```bash
node CI/build-access-examples.mjs --check
```

Картинки находятся в `shared/access-control/static/`.
Их можно вставлять в другие слайды как обычные SVG. Рисунки включаются в qmd обычным Markdown; HTML/SVG в текст не копируется. Виджеты
доступны отдельно в `shared/access-control/index.html`;
параметр `?view=mac` выбирает отдельную модель, `?view=comparison` — сравнение.
Обычный скрипт работает при открытии через `file://`.

В главе и презентации используются общие JS/CSS, подключаемые локальным
фильтром только при наличии native Div виджета. Три статические картинки сохраняются независимо от JavaScript;
в печати интерактивные элементы скрываются. В слайдах сравнения нет.

## Выбор представления

[Mermaid встроен в Quarto](https://quarto.org/docs/authoring/diagrams.html)
и удобен для графа ролей. Однако внешние связи могут менять направление
его подграфов: [ограничение компоновки](https://mermaid.js.org/syntax/flowchart.html#limitation).
Для фиксированных зон и столбцов MAC это потребовало бы дополнительных обходов.
[Graphviz/Viz.js](https://viz-js.com/api/) принимает DOT и возвращает SVG,
но автоматическая компоновка и движок WebAssembly избыточны для трёх
небольших фиксированных композиций.

Здесь выбран YAML как авторское описание и три специализированных SVG-шаблона.
Это локальный формат данного примера, а не новый универсальный язык диаграмм.
Служебные файлы `diagram.mjs`, `widget.mjs` и `widget.css` нужны для изменения
геометрии или поведения; для обычной правки текста открывать их не требуется.
