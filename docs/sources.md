# Источники учебного содержания

Ссылки ниже помогают сопровождать действующие темы курса. Точные ссылки
на обсуждаемые положения следует оставлять рядом с соответствующим текстом.
Для нормативного утверждения нужны официальный текст, его применимая редакция
и основание применения к рассматриваемой системе. Название стандарта или
результат учебной модели не подтверждают соответствие всей системы.

их учебные параметры не служат настройками защиты реальных данных.
