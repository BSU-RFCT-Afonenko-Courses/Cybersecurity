# Предметные опыты криптографического блока

Подготовлены 31 октября — 1 ноября 2026 года в ветке `codex/technical-materials-integration`. Опыты обслуживают изложение в `theory/crypto/` и семинаре 5.

## Размещение

Вход для QMD — `shared/visualizations/crypto/lesson.js`. Он переэкспортирует отдельные предметные функции; вычисления выполняются обычным JavaScript и Web Crypto в браузере.

| Модуль | Экспорты | Назначение |
|---|---|---|
| `random-experiments.js` | `lcgTrainer`, `publicHashChain` | Переход состояния, период, наблюдаемые частоты; открытая цепочка хешей |
| `hash-experiments.js` | `hashBitExperiment`, `truncatedHashCollision`, `fileHashExperiment` | Битовая разность, явно усечённая функция, скачиваемый файл и отдельный эталон |
| `password-experiments.js` | `passwordExperiment`, `passwordSearchCalculator` | Регистрация и проверка PBKDF2; точное число вариантов и условная стоимость |
| `cipher-experiments.js` | `caesarTrainer`, `xorTrainer` | Раздельные опыты над фразой и над байтами |

`lcgTrainer({compact:true})` показывает на слайде управление, подстановку и выходы; статистические подробности доступны отдельно. Формула, смысл состояния и исходные данные остаются видимыми в рассказе. `caesar(text, shift, alphabet)` в `model.js` поддерживает `ru`, `latin`/`en` и совместимый режим `auto`. Прежние экспорты сохранены.

## Контрольные данные

- LCG: `(5x+1) mod16`, `x0=2`; `11,8,9`, цикл 16. Для короткого цикла можно взять `a=4,c=1,m=16,x0=2`: `9,5,5,…`.
- SHA-256 от UTF-8 `abc` и `abb` без перевода строки: один различный входной бит, 124 различных выходных; сетка содержит 256 ячеек.
- Первые 12 бит SHA-256: первая коллизия последовательности `Файл 0`, `Файл 1`, … найдена на вычислении 47; `Файл 16` и `Файл 46`, префикс `2a5`. Полные дайджесты различаются.
- PBKDF2-HMAC-SHA-256: пароль `123456`, соль `000102030405060708090a0b0c0d0e0f`, 1000 итераций, 256 бит дают `6e3849111be8d3070634220666e93c55dbfd75e923f34d35716805464c0a7eaf`.
- Цезарь: русский алфавит из 33 букв с `Ё`, `Ёж, мир!` при сдвиге 3 даёт `Ий, плу!`. Пробелы, пунктуация и регистр сохраняются.
- UTF-8 `Я`: `d0 af`; XOR с `10 20` даёт `c0 8f`. Повтор потока `10 20 30` для `CAT`/`DOG` даёт `53 61 64`/`54 6f 77`; их XOR — `07 0e 13`.

## Условия интерпретации

Статистика не доказывает криптографическую стойкость. Поиск относится к усечённому хешу. Время PBKDF2 измеряет конкретный браузер; 1000 итераций — учебный параметр. Калькулятор предполагает независимый равномерный выбор и заданную скорость. Соль разделяет вычисления, затратная KDF повышает их цену. Шифры Цезаря и повторяемый XOR не предназначены для защиты данных.

Состояние парольного опыта хранится только в открытой странице. Проверка входа использует снимок регистрации, даже если поля следующей регистрации изменены. Учебный файл скачивается как Blob с точными показанными байтами; совпадение с подменённым эталоном не устанавливает происхождение файла. Web Crypto требует поддерживаемого браузера и безопасного контекста, включая локальный адрес просмотра.
