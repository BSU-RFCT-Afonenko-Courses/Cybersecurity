# Собственные снимки прав Windows

Нужны три связанных снимка: локальная учётная запись, её членство
в группе и разрешения этой группы на файл. При желании добавьте
реальную попытку записи с отказом. Работайте в уже доступной Windows 11 Pro;
устанавливать Windows или дополнительное ПО не требуется.

Редакцию и версию посмотрите в «Параметры → Система → О системе»
и запишите рядом со снимками. В Windows 11 Home оснастка
«Локальные пользователи и группы» может отсутствовать:
в этом случае для списка записей откройте «Параметры → Учётные записи →
Другие пользователи», снимите разрешения файла, а кадр членства пропустите.
Обходные оснастки устанавливать не нужно.

## Подготовка примера

Если подходящие учебные запись и группа уже есть, используйте их имена
вместо приведённых ниже. Для нового примера подготовку выполняйте
из учётной записи администратора.

1. Нажмите правой кнопкой «Пуск» → «Управление компьютером» →
   «Служебные программы → Локальные пользователи и группы → Пользователи».
   Через правую кнопку в списке → «Новый пользователь…» создайте
   **demoReader** с паролем. Не добавляйте эту запись в «Администраторы».
2. Откройте соседний раздел «Группы». Через правую кнопку →
   «Создать группу…» создайте **demoReaders**. Нажмите «Добавить…»,
   введите `demoReader` → «Проверить имена» → «ОК» и завершите создание.
3. В Проводнике создайте новый учебный каталог `C:\AccessDemo`.
   Если такой каталог уже есть, выберите другое имя для нового примера.
   Все дальнейшие изменения разрешений выполняйте только в нём;
   разрешения диска, родительских и системных каталогов не меняйте.
4. Откройте свойства `C:\AccessDemo` → «Безопасность → Дополнительно».
   Нажмите «Отключить наследование» и выберите преобразование
   унаследованных разрешений в явные. Оставьте полный доступ
   для своей учётной записи подготовки, «Администраторы» и «СИСТЕМА»;
   если своей записи нет, сначала добавьте её с полным доступом.
   Удалите остальные записи разрешений только у этого нового каталога.
5. Здесь же нажмите «Добавить → Выберите субъект», укажите `demoReaders`
   → «Проверить имена» → «ОК». Выберите тип «Разрешить», права
   «Чтение и выполнение» и область «Для этой папки, её подпапок и файлов».
   Примените изменения. Запреты отдельно не добавляйте.
6. Включите в Проводнике «Просмотреть → Показать → Расширения имён файлов».
   Создайте внутри каталога файл *Report.txt* с текстом `Версия 1`.

## Что снять

| Снимок | Путь к окну | Что должно читаться |
|---|---|---|
| `windows-demo-users.png` | «Управление компьютером → Локальные пользователи и группы → Пользователи» | Имя **demoReader** в списке локальных записей |
| `windows-demo-members.png` | «Группы» → двойной щелчок по **demoReaders** | Название группы и **demoReader** в списке её членов |
| `windows-demo-permissions.png` | Проводник → *Report.txt* → «Свойства → Безопасность» → выбрать **demoReaders** | Имя файла, выбранная группа, разрешённое чтение; запись не разрешена |

Если полный список разрешений не помещается, дополнительно снимите
«Безопасность → Дополнительно». Он поможет увидеть, не выдана ли запись
через другую группу.

Снимайте окно с заголовком и нужными строками через `Win+Shift+S`,
открывайте результат в «Ножницах» и сохраняйте в PNG. Масштаб и размер
экрана выбирайте по читаемости текста. Пароль в кадр не включайте.

## Необязательная проверка записи

После настройки группы войдите в Windows как **demoReader**.
Откройте обычный Windows PowerShell через поиск в меню «Пуск»,
без запуска от имени администратора, и выполните:

```powershell
whoami
Get-Content 'C:\AccessDemo\Report.txt'
Add-Content 'C:\AccessDemo\Report.txt' 'Версия 2'
Get-Content 'C:\AccessDemo\Report.txt'
```

Ожидаются имя **demoReader**, успешное чтение `Версия 1`, отказ записи
и прежнее содержимое файла. Сохраните фактический вывод в
`windows-demo-write-denied.png`. Если запись прошла, проверьте,
под кем запущено окно и какие разрешения есть у файла; готовое сообщение
об отказе вместо результата не подставляйте.
