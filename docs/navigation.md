# Общая навигация курса

Навигация включена общим `_navigation.yml`, подключённым через `metadata-files` у портала и подпроектов. Внутренний список ссылок не задаётся: полный `quarto render` берёт состав и порядок из `subprojects`, идентичность участников из той же композиции Course Site, подписи из нативных заголовков индексных страниц Quarto. Первый содержательный H1 имеет приоритет перед титульным блоком книги; номер главы и служебная ссылка-якорь исключаются из подписи. Главная страница участника — `index.html`; единственная презентация может быть входом без оглавления.

Course Site передаёт Navigation только результаты текущей сборки. Каталог, цели и пространства имён QRC не участвуют в выборе пунктов и подписей меню. Navigation заполняет одинаковое меню в штатной HTML-шапке Quarto и в существующих панелях Reveal. Текущий раздел определяется по фактическому размещению страницы. Оглавления книг и поисковые элементы Quarto сохраняются. При `course-navigation.enabled: true` фильтр подключает общий ресурс `course-navigation/html/header.css`: фон, шрифт и цвета кнопок шапки одинаковы в `website` и `book`, независимо от темы содержимого. Ресурс входит в расширение и работает также в самостоятельном проекте без Course Site/Core. Настройки поиска остаются нативными Quarto; Reveal этот HTML-ресурс не получает.

Готовые внутренние ссылки относительные. Дерево результата можно целиком обслуживать nginx локально, разместить на GitHub Pages или под другим URL-префиксом. Публичные `site-url` и `course-url` остаются существующим потребителям и не определяют адреса общего меню. Входная страница, отсутствующая среди текущих outputs, вызывает ошибку полного рендера. Самостоятельный рендер подпроекта не формирует общее меню составного курса.

Кнопка «Аудитория» скрывает постоянные ссылки, нижнюю панель и заметки; список разделов и кнопка «Изучение» остаются. На узком экране разделы расположены над слайдом. Alt+Shift+A переключает эти режимы независимо от раскладки клавиатуры; при вводе в поле формы сочетание не перехватывается.

Изменены установленные копии Navigation/Presentation и точка вызова в Course Site. Course Core и номера версий не изменены. Параметр `book.title` остаётся нативным заголовком титульного блока книги и задаётся отдельно от заголовка главы в QMD. Небольшая проверка без сборки курса: `quarto run CI/navigation/composition.test.ts`.
