# Навигация курса

Фильтр `course-navigation` и настройки меню заданы в собственном `_quarto.yml`
портала и каждого подпроекта: Core требует конфигурацию внутри проекта. Состав и порядок меню берутся из `subprojects` корневого
`_quarto.yml`, названия — из нативных индексных страниц Quarto.
Course Site передаёт Navigation результаты текущей составной сборки.

Меню заполняет HTML-шапку Quarto и панели Reveal. Текущий раздел определяется
по расположению страницы; оглавление и поиск книг остаются нативными.
Внутренние URL меню относительные. Собранное дерево можно открыть локально
или разместить под префиксом сайта. Для меню Reveal при `file://` применяется
описанная в [UPSTREAM.md](../UPSTREAM.md) поправка: переходы состава курса
открывают соответствующий `index.html`. Самостоятельная сборка подпроекта
не формирует общее меню всего курса.

## Ссылки в материалах

Reference Catalog использует пространства имён:

| Проект | Пространство имён | Папка результата |
| --- | --- | --- |
| Портал | `portal` | Корень сайта |
| Теория | `theory` | `theory/` |
| Банк и работы | `tasks` | `task/` |
| Слайды | `practice` | `seminars/` |

Внутри проекта используйте `@sec-*`, `@exr-*`, `@fig-*`.
Для ссылки между проектами добавляйте пространство имён, например
`@tasks:sec-control-demo` или `@theory:sec-theory-authorization`.
Пространство имён обозначает каталог ссылок, а не дополнительную папку URL.
Связывайте действующие учебные объекты непосредственно; промежуточные
HTML-страницы и карты старых адресов не нужны.

В слайдах ссылка на подробности имеет короткую подпись `[*]`:

```markdown
{{< xref theory def-access-authentication "[*]" >}}
{{< xref tasks exr-data-trust-key-roles "[*]" >}}
```

Это штатный shortcode Reference Catalog: пространство имён, ID и явный текст.
Содержательное объяснение и условие остаются на экране. Для внешнего источника
используйте Markdown-ссылку с тем же видимым текстом и названием в `title`.

## Разделы презентации

Общие настройки всех семинаров находятся в `seminars/_quarto.yml`.
Заголовок `##` начинает тематическую группу, `###` — экран внутри неё.
Сдвиг `-1` превращает их в H1/H2 Reveal; Navigation берёт группы из итоговых H1.
Титульный экран создаётся из YAML `title`. Подтемы не заменяют ручным списком
ссылок на первом слайде. Внутренние заголовки упражнений имеют уровень `####`.

Панель слева показывает группы; на узком экране они доступны через меню.
Нижняя панель содержит управление слайдами, поиск и обзор.
`CI/check-slides.py` проверяет наличие групп, титула и подключение Navigation
в готовых презентациях.

## Режимы слайдов

Кнопка «Аудитория» скрывает постоянные ссылки, нижнюю панель и заметки.
Список разделов и кнопка «Изучение» остаются доступными.
`Alt+Shift+A` переключает режим независимо от раскладки клавиатуры;
при вводе в поле формы сочетание не перехватывается.

Общая HTML-шапка и панели Reveal реализованы установленными Navigation
и Presentation. Их номерные версии перечислены в [реестре пакетов](../UPSTREAM.md).
