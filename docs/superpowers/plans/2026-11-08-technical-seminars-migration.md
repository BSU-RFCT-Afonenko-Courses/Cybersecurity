- Пересматриваются все задания и решения 4–7, включая условия непосредственно на слайдах. Пройденность занятия не ограничивает редакторский объём.

- Условие задаёт понятное действие и критерий результата. Открытые вопросы допускают разные обоснованные решения; ключ не требует единственной авторской формулировки. Для выбора нужны заданные основания, для контрпримера — проверяемое утверждение. Поиск «главного документа» или общих «нужных сведений» без конкретного предмета проверки заменяется задачей с данными и результатом.
- Ситуация должна давать естественный повод для вопроса. Не заменять общий опрос искусственным требованием сконструировать пример только ради нужного автору вывода. Исходный пункт о фотографии с корпоратива оставить без изменений по указанию пользователя.
- Состав 5 остаётся узнаваемым. Генераторы — криптографические свойства, источники энтропии, физические и аппаратные средства; количественный прогноз LCG — дополнительная работа.
- Лэмпорт включён в общее занятие. Ручной RSA не обязателен. Сертификаты — доверие, цепочки и упоминание отзыва; задачи о сроках и времени подписания исключены.
- Статическую и динамическую целостность нужно объяснить. Отдельные задачи по ним пока не выбраны.
- Копирование — основная практика 7; RAID — основной принцип и пара иллюстраций. Хэмминг и CRC вручную не рассчитываются; точный набор простых кодов ещё обсуждается.
- Ориентир решения и обсуждения — около 40+20 минут, без назначенного смысла частей и обещания уместить туда все первые объяснения.
- Теория, включая объяснения на слайдах и общие рисунки, получает отдельное согласование до применения.
- Старые адреса и расположение перестраиваются свободно; переходники и сохранение исторических номерных ID не требуются.
- Один действующий источник условия и парного решения. Используются штатные учебные элементы и профили `student`/`full`.
- Новая авторская проза — по-русски. Слайды содержат необходимые понятия, данные и вопрос без обязательного перехода по ссылке или чтения notes.

## Размер порции и порядок просмотра

По последнему поручению текстовые задачи 4–7 собраны в один крупный пакет для отложенной рецензии, без промежуточного содержательного согласования отдельных порций. Внутренняя разбивка по З4.1–З7.4 сохранена; К4 для теории это поручение не отменяет.

Обычная порция заданий — 2–3 условия с полными решениями; порция объяснения — один подраздел; порция визуального материала — один рисунок или небольшой законченный показ. Порция сопровождается кратким описанием того, что теперь делает студент и что проверено. Если тематическая группа превышает этот размер, она выполняется несколькими последовательными порциями с тем же идентификатором и номером порции в отчёте.

Обычная последовательность для каждой порции:

1. Прочитать её источники и связанные решения из реестра Р1.
2. Подготовить содержательный результат в указанном черновике.
3. Самостоятельно пройти решение, проверить достаточность данных и границу вывода; для рисунка проверить выбранные состояния.
4. Показать конкретный результат и отметить судьбу исходных материалов в реестре.
5. После исправлений сохранить небольшую законченную порцию отдельным коммитом.

Орфографию, оформление и исправления по уже полученным замечаниям выполнять без нового согласования каждого действия. На содержательный просмотр повторно выносить изменение учебной цели, модели данных, обязательной глубины или ожидаемого вывода. Во время ожидания ответа можно готовить независимую порцию; зависимые решения не считать принятыми по истечении времени.
