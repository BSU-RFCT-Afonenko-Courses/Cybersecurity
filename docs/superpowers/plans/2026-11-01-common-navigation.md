# Общая навигация готового курса

Согласованный сценарий: полный `quarto render`. Состав и порядок берутся из `subprojects`, идентичность участников — из Course Site, подписи — из нативных заголовков Quarto. В Navigation нет отдельной карты href и current. Вход — фактический index.html, либо единственная презентация подпроекта.

Реализация: Course Site передаёт готовые outputs и метаданные участников в установленный Navigation. Тот использует нативные заголовки страниц и относительное размещение outputs, заполняет штатную navbar Quarto и существующий Reveal UI. Все внутренние ссылки записываются в готовый HTML относительно текущей страницы. Отсутствующий вход полного результата — ошибка до записи изменений. Core и существующие поля публичного адреса не меняются.

В аудитории скрываются панели и выходы к курсу, остаются список разделов, слайд и кнопка «Изучение». Alt+Shift+A переключает режим через существующий Presentation; поля ввода не перехватываются.

Проверки ограничены одним примером готовых HTML, проверкой конфигурации и синтаксиса и коротким проходом режима аудитории на ранее собранном примере. Полный курс не пересобирается; выпуск/публикация/изменение версий не выполняются.
