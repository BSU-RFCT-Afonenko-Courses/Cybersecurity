# Установленные инструменты

Исходная поставка — quarto-template-course v1.0.0. В этой миграции курс остаётся
самостоятельным учебным репозиторием; новый template является сайтом документации.

Выбранные выпуски: quarto-course v3.0.1 (Core/Presentation/Navigation вместе),
quarto-project-publish v4.0.0, quarto-reference-catalog v2.2.0,
quarto-project-download v1.1.0. Установленные bytes закреплены в Git и обновляются
штатным quarto add. Здесь нет менеджера зависимостей и собственного Markdown-парсера.

Новая форма: root subprojects, course.id только в корне, task-items, нативные
условия профиля. Старый синтаксис не поддерживается. Миграция выполняется один раз.
Общая библиография находится в root references.bib; проекты подключают ../references.bib.

Существующие авторские материалы и незакоммиченные удаления перенесены в рабочую
ветку без изменения исходного checkout. Учебное наполнение контрольных и большинства
тематических страниц остаётся заготовкой автора и не выдаётся за готовое содержание.
