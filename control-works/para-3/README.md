# Печатные варианты контрольной работы: пара 3

Варианты используют общие стили и компоненты из `../fundamentals`.
Для сборки из этой папки нужны Typst и шрифт Times New Roman:

```bash
mkdir -p _output
typst compile --root .. variant-3.typ _output/variant-3.pdf
typst compile --root .. variant-4.typ _output/variant-4.pdf
```

Каждый вариант предназначен для двусторонней печати на листе A4.
