# Схемы управления доступом

`static/overview.svg` показывает субъект, монитор, политику и объект;
`static/procedures.svg` — идентификацию, аутентификацию и авторизацию.
Это общие рисунки теории и слайдов.

В каталогах `dac`, `mac`, `rbac` находятся предметные `model.js`,
интерактивные `lesson.js`, редактируемые SVG моделей и DOT алгоритмов.
`static/model.svg` задаёт композицию интерактивной схемы,
`static/overview.svg` — статический обзор. Эти SVG редактируются непосредственно;
общий сборщик обновляет только рисунки, для которых есть DOT в `graphs/`.

Семантические идентификаторы групп SVG используются для подсветки;
при изменении композиции согласуйте их с ключами этапов в `model.js`.
`display.js` соединяет предметные данные с общим runtime. У каждой модели
свои запросы, трасса и управление. Внешнюю подпись и номер задаёт Quarto.

Подготовка ресурсов, включение OJS и устройство этапов описаны
[в руководстве визуализаций](../../../docs/content/visualization-authoring.md).
