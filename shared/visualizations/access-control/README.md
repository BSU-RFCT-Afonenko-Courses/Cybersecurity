# Восстановленные схемы управления доступом

`static/overview.svg` — сохранённая общая схема из `cb86e1a` (29 октября 2026 года).

В `dac/static/model.svg` и `rbac/static/model.svg` находятся непосредственно редактируемые авторские SVG: матрица → ACL из `cb86e1a` и подтверждённая схема Moodle из `07b4b91`, сохранённая в `33c1df5`. Их копии `overview.svg` используются как статические рисунки. Именованные группы нужны для подсветки; содержательные подписи остаются внутри рисунка.

MAC восстановлен из `33c1df5:experiments/visualizations-4-5/iteration-2/`. `mac/static/model.svg` — редактируемый исходник восстановленной композиции. Он дополнен совместимыми группами `process` и `file-1`–`file-3`; они не меняют вид. `mac/static/overview.svg` показывает два допустимых направления. DOT для этих композиций не хранится: общий сборщик не должен перезаписывать авторские SVG новой раскладкой. Краткие алгоритмы редактируются в `*/graphs/algorithm.dot` и обновляются Graphviz.

`display.js` использует установленный runtime визуализаций, включая изоляцию идентификаторов и подсветку этапов. Предметные запросы, трассы и подсветка находятся в `*/model.js` и `*/lesson.js`. Внешние подписи и номера задаёт Quarto.
