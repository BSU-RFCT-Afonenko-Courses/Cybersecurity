# Обвязка учебных визуализаций

Локальное расширение Quarto 0.1.0. Владелец исходника и будущего отдельного выпуска —
Афоненко Анатолий, сопровождающий курс. Отдельный репозиторий и публичный выпуск
этой работой не создаются; перенос в организацию Course-Tools потребует отдельного
решения владельца. Установленные пакеты Course Core/Presentation не изменяются.

Установка целиком из корня каждого нативного проекта:

```sh
quarto add ../extensions/course-visualizations --no-prompt
```

Добавьте `course-visualizations` к существующим filters, сохранив Core/Presentation.
Фильтр уже подключён в theory/_quarto.yml и seminars/_quarto.yml.
Отдельный профиль pilot выбирает только проверочные документы; обычная навигация не меняется.
При изменении исходника повторяйте штатную установку в обоих проектах.

Расширение содержит только управление независимым выбранным этапом, SVG id,
подсветку, ограниченные контейнером стили и доставку статического SVG
через штатный mediabag. ES-модуль доступен как
`_extensions/course-visualizations/browser/runtime.js`. Модуль курса
`shared/visualizations/common/runtime.js` — короткий совместимый вход;
подготовка заменяет в его локальной копии только путь установки.

У расширения нет правил доступа, криптографических вычислений, банка, пояснений,
заголовков рисунков или генератора OJS из Lua. Оно принимает готовые трассы и SVG;
Quarto компилирует авторские OJS-ячейки раньше Pandoc-фильтров.
Статический SVG предварительно материализуется курсом в `_prepared/visualizations`;
сам фильтр не выбирает предметную модель и не формирует новые учебные элементы.

Проверена связка Quarto 1.11.6 / Core и Presentation 8.2.8. Владелец общей обвязки
сопровождает API, доступность управления, id/ссылки SVG и доставку ресурсов.
Автор курса сопровождает предметные JS/DOT/OJS, запросы, данные и пояснения.
Несовместимое изменение трассы или путей установки требует изменения версии
расширения и авторского руководства. Гарантии других версий Quarto проверяются
отдельно; автоматический PDF интерактивного состояния не заявляется.

Точный интерфейс и включения: `docs/content/visualization-authoring.md` курса.
