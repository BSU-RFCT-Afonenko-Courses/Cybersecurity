# Общая тема HTML курса

`course-theme-html` — явно включаемый формат Quarto на основе Cosmo. Он использует
системные шрифты и общую палитру Navigation; Google Fonts не загружаются.
Отдельные папки `styles` в проектах не нужны. Тема устанавливается вместе с
расширениями этого репозитория и не включает Core, Presentation или Navigation.

Для сайта или книги замените HTML-формат:

```yaml
format:
  course-theme-html:
    toc: true
```

Остальные HTML-параметры Quarto сохраняются. При переходе удалите прежние
подключения `styles/offline-fonts.scss` и сами дублирующиеся файлы. Если параметры
HTML заданы в профилях, используйте там то же имя `course-theme-html`.
Для Reveal сохраняйте `format.revealjs.theme: default` либо выбранную тему слайдов.
Цвета и шрифты принадлежат теме; Navigation определяет структуру и доступность
меню через CSS-переменные `--course-nav-*`. Логотип курса остаётся в его бренде.
