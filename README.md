# Основы кибербезопасности

Курс состоит из главной страницы, книги теории, банка задач с работами и слайдов
семи занятий. Исходники редактируются в Quarto. Повторно используемые условия
и решения хранятся в банке; демонстрационный вариант контрольной содержит
свои условия и материалы для подготовки в файле работы.

| Каталог | Содержание |
| --- | --- |
| `theory/` | Самостоятельная теория по предметным зависимостям |
| `task/bank/` | Условия, решения и материалы для чтения |
| `task/works/` | Назначения занятий и работ; условия демонстрационной контрольной |
| `seminars/` | Слайды Reveal.js и каталог занятий |
| `shared/visualizations/` | Предметные модели, опыты, SVG и DOT |
| `extensions/course-visualizations/` | Общая обвязка интерактивных рисунков |
| `control-works/` | Печатные варианты Typst и общие элементы бланка |
| `CI/` | Установка, сборка, проверки и локальный просмотр |
| `docs/` | Действующие руководства автора |

## Подготовка

Для локальной сборки используется системный Quarto **1.11.6**;
минимальная поддерживаемая версия **1.11.5** проверяется в CI.
Также нужны Python 3, Node.js и Graphviz (`dot`). Python-зависимости перечислены в
`CI/requirements-visualizations.txt`.

Расширения уже находятся в репозитории. Закреплённые выпуски и воспроизводимая
локальная поправка Navigation для просмотра файлов описаны в [реестре пакетов](UPSTREAM.md).

Для повторной установки закреплённых внешних и авторских пакетов:

```sh
bash CI/install-extensions.sh
```

## Сборка и просмотр

Профиль `student` предназначен для публикации. Профиль `full` содержит доступные
преподавателю решения и собирается отдельно. Видимость учебных элементов
определяет Course Core.

```sh
bash CI/render.sh student
bash CI/render.sh full
```

Готовые сайты находятся в `_site-student/` и `_site-full/`; отдельные результаты —
в `{theory,task,seminars}/_output/{student,full}/`. Откройте `index.html`
нужного сайта как локальный файл. Объяснения, схемы и условия семинаров 1–7
доступны без сервера; решения остаются в банке. Для интерактивов OJS используйте HTTP:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory _site-student
```

Откройте <http://127.0.0.1:8000/>. Сервер показывает существующие файлы;
остановка — `Ctrl+C`. Просмотр отдельных экспортов без копирования в общий сайт
описан в [руководстве просмотра](CI/README-preview.md).

Сборки выполняйте последовательно. Пока Quarto работает, не изменяйте исходники,
документацию и конфигурацию: Course Core проверяет неизменность снимка проекта.

## Логотип

Общий пакет `_extensions/course-brand` содержит основной SVG «Кибер котость»,
иконку и декларацию `brand.yml`. Quarto использует иконку в верхней навигации
и вкладке браузера, основной рисунок — в боковой панели книг и на слайдах.
После изменения пакета обновите копии в подпроектах:

```sh
bash CI/install-course-brand.sh
```

## Проверки и публикация

Команды проверки исходников, нативной модели и готовых сайтов приведены
в [руководстве сборки](docs/build.md). `CI/render.sh` сохраняет журналы
в `_generated/ci-logs/` и передаёт код завершения Quarto.

Workflow `.github/workflows/pages.yml` задаёт проверки PR и ветки `master`.
Сообщение коммита `[skip ci]` используется для изменений, которые должны быть
отправлены без автоматического запуска. GitHub Pages настроен на ветку
`gh-pages`: в неё отдельно публикуется проверенный `_site-student` из `master`.
Условный шаг публикации через Actions требует `COURSE_PUBLISH_PAGES=true`
и переключения источника Pages на GitHub Actions; ветку `gh-pages` он не обновляет.
Преподавательский сайт, Body-пакеты и служебные исходники не публикуются.
