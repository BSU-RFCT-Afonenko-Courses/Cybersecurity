# Основы кибербезопасности

Курс состоит из главной страницы, книги теории, банка задач с работами и слайдов
семи занятий. Исходники редактируются в Quarto; условия и решения хранятся в банке
и используются в работах и на слайдах.

| Каталог | Содержание |
| --- | --- |
| `theory/` | Теория по темам |
| `task/bank/` | Условия, решения и материалы для чтения |
| `task/works/` | Назначения задач на занятия и работы |
| `seminars/` | Слайды Reveal.js и каталог занятий |
| `shared/visualizations/` | Предметные модели, опыты, SVG и DOT |
| `extensions/course-visualizations/` | Общая обвязка интерактивных рисунков |
| `control-works/` | Печатные варианты Typst и общие элементы бланка |
| `CI/` | Установка, сборка, проверки и локальный просмотр |
| `docs/` | Действующие руководства автора |

## Подготовка

Нужны Quarto **1.11.6 или новее**, CUE **0.17.1**, Python 3, Node.js
и Graphviz (`dot`). Python-зависимости перечислены в
`CI/requirements-visualizations.txt`.

Расширения уже находятся в репозитории. Установленные Navigation, Presentation
и Site содержат локальные изменения; перед повторной установкой сверяйте
[реестр пакетов](UPSTREAM.md), чтобы сохранить их.

Для установки закреплённых внешних пакетов и логотипа предусмотрен скрипт:

```sh
bash CI/install-extensions.sh
```

Авторское расширение визуализаций устанавливается из его каталога:

```sh
(cd theory && quarto add ../extensions/course-visualizations --no-prompt)
(cd seminars && quarto add ../extensions/course-visualizations --no-prompt)
```

## Сборка и просмотр

Профиль `student` предназначен для публикации. Профиль `full` содержит доступные
преподавателю решения и собирается отдельно. Видимость учебных элементов
определяет Course Core.

```sh
bash CI/render.sh student
bash CI/render.sh full
```

Готовые сайты находятся в `_site-student/` и `_site-full/`; отдельные экспорты —
в `{theory,task,seminars}/_output/{student,full}/`.
Для просмотра собранного публичного сайта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory _site-student
```

Откройте <http://127.0.0.1:8000/>. Сервер показывает существующие файлы;
остановка — `Ctrl+C`. Просмотр отдельных экспортов без копирования в общий сайт
описан в [руководстве HTTP-просмотра](CI/README-preview.md).

## Логотип

Общий пакет `_extensions/course-brand` содержит основной SVG «Кибер котость»,
иконку и декларацию `brand.yml`. Quarto использует иконку в верхней навигации
и вкладке браузера, основной рисунок — в боковой панели книг и на слайдах.
После изменения пакета обновите копии в подпроектах:

```sh
bash CI/install-course-brand.sh
```

## Проверки и публикация

Команды проверки исходников, выбранных Body-пакетов и готовых сайтов приведены
в [руководстве сборки](docs/build.md). `CI/render.sh` сохраняет журналы
в `ci-logs/` и передаёт код завершения Quarto.

Workflow `.github/workflows/pages.yml` задаёт проверки PR и ветки `master`.
Сообщение коммита `[skip ci]` используется для изменений, которые должны быть
отправлены без автоматического запуска. Публикация student-сайта разрешается
отдельно: из `master` при `COURSE_PUBLISH_PAGES=true`. Преподавательский сайт,
Body-пакеты и служебные исходники в публичную выдачу не входят.
